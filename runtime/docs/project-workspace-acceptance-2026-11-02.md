## 实现范围

- 智能问答：选择执行配置和模式，提交任务，查看答案、证据及可展开的执行记录；保留暂停恢复和JSON/HTML导出。
- 数据来源：读取所选配置注册的公开来源元数据，支持搜索和详情；不把目录摘要当作文件全文。
- 任务历史：查看持久运行记录、搜索问题并重新打开结果。
- 实验评估：模板下载、JSON导入、模式比较和JSON导出。指标缺失保持null，不生成成绩；不同样本数提示不能直接比较。
- `create_app(profiles=...)`通过可信服务端`ExecutionProfile`注册实际端口。每次run/resume使用fresh异步上下文；浏览器不提交代码、密钥或本地路径。配置缺失或变化时在打开factory前拒绝恢复。

当前包版本0.7.0；核心契约v0.5，JSON封套1.0。LangGraph负责14个实际流程节点，原控制器负责授权、预算、工具调度和证据，SQLite调用日志继续负责安全恢复。公共run/resume和队友端口不变，详情见[LangGraph流程说明](langgraph-workflow.md)。

## 0.6.1收尾自审与独立审查

1. `runtime._Controller._call`：adapter吞掉调用方取消后返回有效结果或改抛异常，原来可能继续执行或返回普通失败。现在在超时上下文退出后的finally比较新增取消请求，保留取消传播，停止后续派发，未知模型请求只保守计一次。数据/规划×返回/异常4项回归通过。
2. `web.service.DemoService._execute`：审计故障可以返回RunResult但不保存核心终态，原来网页无差别写成永久失败。现在读取SQLite的`state.result`判断终态，未终结时显示interrupted；资源清理正常/异常/取消×即时/重启恢复6项回归通过，未知结果仍由内核拒绝。
3. 核心契约补齐默认值、观察来源授权、schema限制、目录重注册和可选TraceSink扩展，并修正成功样例计数；19个JSON样例严格验证、28个RunConfig字段核对通过。
4. README补充仓库根启动、macOS/Linux/WSL环境、队友端口职责与最小联调步骤；独立复查修正DataPort无usage字段的说明。新增根.gitignore，经临时Git目录验证8类本地/私密路径被排除、10项交付/示例路径保留。
5. 提案ZIP移除AppleDouble元数据，只保留两份与工作区逐字节一致的LaTeX源；正式提案内容不变。

该0.6.1审核的逻辑、边界、并发与资源自审及独立审查未发现新增阻塞问题。当时文档检查覆盖7份Markdown的44个本地链接、11段Python代码；凭据静态筛查未发现真实密钥，尚未初始化项目Git或推送远端，未请求外部模型。

## 0.6.0自审和独立审查修复

1. 端口factory退出清理异常或取消曾可能覆盖已完成答案。核心结果现在在退出上下文前保存，清理异常只补诊断，不丢失终态或开放错误恢复入口。
2. 直接调用评估仓储时，过长时间字符串曾可能写出超过读取上限的记录。日期限制64字符，并在原子发布前检查序列化大小；绕过模型构造校验仍不能写入超限记录。
3. 最终浏览器点击评估导出未触发下载；此路由与其他正常下载路由的差异是只有网页download属性。新增响应头回归先失败，再由服务端返回Content-Disposition附件头后通过；相同浏览器点击随后实际下载成功。报告ID由仓储验证后进入响应头，JSON结构及fetch读取保持兼容。

前端同时审查了选择竞争、过时响应、重叠轮询、超时、artifact缓存边界、文本渲染和评估原JSON校验。独立审查确认以上实质问题均已修复；112项相关回归曾以警告视为错误通过，最后下载修复的单例独立复测亦通过。未发现本轮范围内尚未修复的实质问题。
